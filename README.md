# Cloud Carbon Footprint Analytics Platform

This project analyzes the environmental impact of cloud infrastructure usage.

It estimates carbon emissions generated by workloads based on compute usage, storage, network transfer, and region.

## Features

- Carbon footprint calculator
- Cloud usage dataset generator
- Dataset analytics dashboard
- Carbon emission trends
- Region comparison
- Multi-cloud comparison (AWS, GCP, Azure)
- Sustainability scorecard
- Carbon emission forecasting

## Tech Stack

Python  
Streamlit  
Pandas  
Plotly  
NumPy  

## Run the Project

Install dependencies:

pip install -r requirements.txt

Run the app:

streamlit run app.py

## Project Goal

Help organizations analyze and reduce the environmental impact of their cloud workloads.
